# What your Hive Mind has learned

One line for each note in this folder: the subject, where it came from, and when to open it. Claude reads this list before work on a subject and opens only the notes that fit. Notes are added by the front door (the `hive-intake` helper) when you send something worth keeping.

A line reads: `- <note's file name>: <the subject> (from <source>, <date>). Open it when <...>.`
