# Setup guide

The setup guide now lives in the manuals, one page per need:

- **Setting up for the first time:** [Your first hour](docs/first-hour.md). Numbered steps, what you should see after each one, and what to do if something else happens. Windows, with boxes for Mac and Linux.
- **A save was refused, or anything else looks wrong:** [When something breaks](docs/when-it-breaks.md). It also says how to undo everything.
- **What setup puts on your computer, and how to remove each part:** [Every part explained](docs/parts.md).
- **What to say every day, and how to add a skill, a tool, a rule or a habit:** [Every day](docs/daily-use.md).

In short: you need Claude Pro or higher (the free plan does not include Claude Code), the Claude desktop app, and a free GitHub account. Claude installs Git and Node for you, after your yes. Nothing is installed, connected or sent without your yes, and everything setup changes in Claude can be undone.
