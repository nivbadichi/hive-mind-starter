# Answers from your page

The page adds a line here when you answer a question or leave a note on it. Claude acts on each open line at the start of the next chat, then ticks it and writes what it did.

A line reads: `- [ ] when | answer or note | project | the question | what you said`

The project column is the project's folder name under `projects/` (for example `my-shop`), not the name shown on your page.

Example (an answered line, after Claude acted on it):
`- [x] 2026-11-17 09:12 | answer | my-shop | When should the shop open? | The first of April | done: next step set to "Plan the opening week"`
