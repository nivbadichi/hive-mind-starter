# Words we use

Every word in these manuals that may be new to you, in plain words. If a word is missing here, ask Claude "what does <the word> mean?".

| Word | What it means |
|---|---|
| **Chat** | One conversation with Claude. |
| **Code tab** | The part of the Claude app where Claude can work with the files on your computer. Hive Mind lives there. |
| **Claude Code** | The part of Claude that works with files and programs on your computer. It comes with Claude Pro and higher, not with the free plan. |
| **Plugin** | A ready-made package that adds helpers and checks to Claude in one step. Hive Mind can be added as one. |
| **Marketplace** | A list of plugins that Claude can add from. Hive Mind has its own short list with one entry: Hive Mind. |
| **Home folder** | The folder with your user name: `C:\Users\<your name>` on Windows, `/Users/<your name>` on a Mac. |
| **Your notes** | What Claude writes down so the next chat knows it: the `hive-mind` folder. Plain text files you can open yourself. |
| **Your private copy** | Your own copy of your notes on GitHub, which only you can read. |
| **GitHub** | A website that keeps files online. Your private copy lives there. |
| **Repository** | GitHub's word for a folder of files kept online. Your private copy is one. |
| **Template** | A starting copy on GitHub. "Use this template" makes a fresh copy of it on your account. |
| **Fork** | Another kind of copy on GitHub that stays linked to the original and cannot be made private. Hive Mind is never forked. |
| **Git** | The free program that saves your notes and sends them to your private copy. |
| **Node** | A free program that runs the privacy check and Hive Mind's small programs. |
| **Docker** | A free program that runs a project's code inside a sealed box on your computer, so a mistake in the code cannot reach your own files. Only projects with code need it. |
| **Container** | One of those sealed boxes. It holds a copy of the project's files and nothing else of yours. |
| **Save** | Keeping your notes as they are now, first on this computer and then in your private copy. |
| **Terminal** | A window where you type commands. You need it only for a few steps on a Mac or Linux, and never on Windows. |
| **Command** | A line of text that tells the computer to do one thing, such as `git --version`. Claude types them for you and asks first. |
| **Permission mode** | How much Claude may do before asking you. **Manual** means it asks before every change or command. |
| **The start step** | A small script that makes every new chat read your notes before it answers, and shows the HIVE MIND box. |
| **HIVE MIND box** | The small box at the top of a new chat: whether your notes are saved, and which project you are in. |
| **Checks, gates** | Small programs that hold Claude to your rules, so they are not just advice. Hive Mind calls them gates. "gates off" and "gates on" switch them. |
| **Hook** | Claude's word for a small program it runs at set moments, such as the start of a chat or before a save. The start step and the checks are hooks. |
| **Save hook** | The hook that runs the privacy check every time your notes are saved. |
| **Privacy check** | Runs before every save, and refuses passwords, keys and the private names you gave. |
| **Private names** | Names that must never be saved in your notes, such as an employer or clients. Kept only on this computer. |
| **Helper** | A short instruction file Claude follows for one job, such as setting up or closing a chat. A second Claude sent off to do part of the work is also called a helper. |
| **Skill** | A set of instructions Claude follows for one kind of job, such as making slide decks. Helpers are Hive Mind's own skills. |
| **Tool, connector** | A connection between Claude and another service, such as your calendar. Claude calls it a connector. Each connects only after your yes. |
| **Rule** | Something that must always hold, such as "always ask before booking anything". |
| **Habit** | How you like things done, such as short answers. Hive Mind also calls these preferences. |
| **Starting set** | The ready list of skills, tools, rules and habits your Hive Mind starts with. You pick its size (Light, Standard or Full) and its kind (everyday, student, builder, designer or small business). Nothing on it is installed or connected without your yes. |
| **Places** | The parts of your page: Today, Initiative, Life and System come with every Hive Mind; you add your own. |
| **Project** | Something you are working on, with its own note: where it stands and its next step. |
| **Brief** | A short note at the start (and, if you like, the end) of your day: what needs you and your best moves. |
| **The cloud** | Computers run by Anthropic, where Claude can work while your computer is off. The daily brief runs there. |
| **Your page** | A private web page where you will see what needs you. Not in this copy yet. |
| **Health check** | Claude checks every part and tells you what needs you. Say "run the health check". |
| **Installer** | The small program that puts the parts in place in Claude on this computer, after your yes. |
| **winget** | Windows' own program for installing other programs. Claude uses it to install Git and Node. |
| **Backup, `.bak-`** | A dated copy of a file, kept before it is changed, so it can be put back. |
